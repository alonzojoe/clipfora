## Clipfora

A macOS app for clipping content, built with Electron, React, TypeScript and Tailwind CSS.

```bash
npm install        # install dependencies and the Electron binary
npm run dev        # run the app with hot reload
npm run build:mac  # package a macOS build into dist/
```

`npm run lint`, `npm run typecheck` and `npm run format` check and format the code.
